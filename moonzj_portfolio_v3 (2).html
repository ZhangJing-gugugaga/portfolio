第一章 · 上弦月 (右半圆照亮 50%) // 我是谁

不写流水线式的简历套话，
只用三件事定义我的工程审美。

当模板式的个人网站都在罗列“精通某某框架 90%”时，我更愿意向你展示：面对失控的工具、昂贵的算力与易碎的排版，我选择怎样动手解决。

克制的造物者

偏爱零冗余的架构。无论是仅凭 Python 标准库与物理 ID 精准驱动幻灯片母版重构，还是将上百行冗长规则提炼成精悍的指令契约，我都追求“少即是多”的工程秩序感。

偏执的修墙人

不相信停留在纸面上的“安全建议”。经历过凌晨被跨平台脚本静默清空桌面的阵痛后，我习惯把防御写进钩子、快照与网络边界，并在开源社区为数千星项目修补自定义网关死锁。

求真的算账人

拒绝人云亦云的行业狂欢。为了看清智能体底层的真实损耗，我会拆开本机上万轮请求的账单、手写双进程服务实测协议容灾，把每一次技术选型建立在亲手验证的证据之上。
